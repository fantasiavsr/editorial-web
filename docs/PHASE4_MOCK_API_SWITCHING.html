Mock/API Switching Architecture

Phase 4 — The major architectural checkpoint

Complete & Verified

Overview

Phase 4 implements the abstraction layer that allows the React frontend to seamlessly switch between mock data (for development and Vercel deployment) and real API calls (for production). This is the critical architectural checkpoint where the two deployment modes converge.

🎯 The Key Insight: React components use a single unified interface. The underlying data source (mock or API) is controlled by environment variables — components don't need to know or care which one is active.

The Two Deployment Modes

MOCK Demo / Vercel
  • Uses local mock data
  • No backend required
  • Works offline
  • Instant "API" responses
  • Perfect for demos
  • Configured via .env
VITE_DATA_SOURCE=mock
API Production / Real Domain
  • Uses Laravel API
  • Queries MySQL database
  • Real CRUD operations
  • Network requests
  • Persisted data
  • Configured via .env.local
VITE_DATA_SOURCE=api
VITE_API_URL=http://localhost:8000/api

The Abstraction Layer

Located in src/services/data.js, the abstraction layer provides a single interface for components:

import { productDataSource } from './services/data.js'

// Same interface, any data source
const products = await productDataSource.getAll()
const product = await productDataSource.getById(1)
await productDataSource.create(newProduct)
await productDataSource.update(id, changes)
await productDataSource.delete(id)

How It Works

At runtime, the data service checks the environment variable and routes requests appropriately:

React Component ↓ productDataSource.getAll()
Check VITE_DATA_SOURCE
✓ mock → MockProducts array
✓ api → Laravel API fetch()

Mock mode simulates network delays with setTimeout so responses feel realistic. API mode uses real fetch() calls to the Laravel backend.

Key Architecture Features

✓ Seamless Switching

Change one environment variable, no code changes needed. Both modes provide identical data shapes.

✓ Loading States

Dashboard shows spinner while loading, error message if something fails, with manual retry option.

✓ Error Handling

All functions throw catchable errors. Components can handle failures gracefully.

✓ Mock Mode Parity

Mock mode simulates network delays so behavior matches API mode. Mutations (create/update/delete) update the mock array.

✓ Environment-Aware

Respects Vite's environment system. Different .env files for dev, local, and production.
